# Портфолио: аналитик данных

Проекты, выполненные самостоятельно во время обучения по программе «Аналитик данных» в Яндекс Практикуме (2025–2026). Датасеты и тексты заданий являются материалами курса и в репозиторий не входят; чтобы перезапустить ноутбук, положите файлы данных в папку `data/` рядом с ним. SQL-запросы написаны для учебной базы PostgreSQL Практикума.

| Проект | Задача | Инструменты |
|---|---|---|
| [Рынок видеоигр 2000–2013](video-game-market/) | Очистка и подготовка данных о продажах и оценках игр: типы, пропуски, дубликаты, категоризация оценок, топ-7 платформ | Python, pandas |
| [Рынок общепита Москвы](moscow-catering-market/) | Исследовательский анализ заведений Москвы для выбора формата, района и ценового уровня нового заведения | Python, pandas, matplotlib, seaborn, phik |
| [Исследование стартапов](startup-investments/) | Анализ финансирования стартапов и доли возврата средств: рекомендация инвестору по сегменту рынка и типу финансирования | Python, pandas, matplotlib |
| [GoFast: аренда самокатов](gofast-hypothesis-testing/) | Анализ пользователей и поездок, расчёт выручки, проверка гипотез о выгоде подписки, моделирование нормальным распределением | Python, pandas, matplotlib, SciPy |
| [Яндекс Книги и A/B-тест интернет-магазина](yandex-books-and-ab-test/) | Проверка гипотезы об активности пользователей Москвы и Санкт-Петербурга; оценка корректности и результата A/B-теста нового интерфейса | Python, pandas, matplotlib, SciPy, statsmodels |
| [Яндекс Афиша](yandex-afisha/) | Поиск причин снижения среднего чека осенью 2024 года: сезонность, категории, регионы, партнёры; проверка гипотез о мобильных и десктопных пользователях | Python, pandas, matplotlib, seaborn, SciPy |
| [A/B-тест алгоритма рекомендаций](ab-test-recommendations/) | Расчёт размера выборки и длительности теста, проверка корректности разбиения и оценка результата | Python, pandas, matplotlib, statsmodels |
| [Рынок недвижимости Санкт-Петербурга и области](real-estate-sql/) | Ad hoc запросы: связь срока продажи квартир с ценой и площадью по регионам, сезонность публикации и снятия объявлений | SQL (PostgreSQL) |
| [«Секреты Тёмнолесья»: внутриигровые покупки](temnolesye-game-sql/) | Доля платящих игроков по расам, статистика и аномалии стоимости покупок, популярность эпических предметов, влияние расы на активность покупателей | SQL (PostgreSQL) |
| [DataLens: сервис доставки еды](https://datalens.yandex/l6rqgz2l7thk4) | Дашборд «Ключевые бизнес-метрики в Саранске (май — июнь 2021)» для сервиса доставки еды | DataLens |
| [DataLens: конференции TED](https://datalens.yandex/70q11mv85b5er?_theme=dark) | Дашборд «Активность конференций TED» | DataLens |
| [DataLens: продажи Яндекс Афиши](https://datalens.yandex/6237bck3qoaqp) | Дашборд по анализу продаж сервиса Яндекс Афиша | DataLens |
